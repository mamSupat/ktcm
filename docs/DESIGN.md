# Template Layout (หน้าจอออกแบบ)

- Login Screen: ชื่อระบบ, username, password, ปุ่มเข้าสู่ระบบ, error message
- Dashboard: จำนวนผู้ใช้, รอบประเมิน, งานทั้งหมด, งานที่ประเมินเสร็จ, รายการติดตาม
- Personnel/Admin: จัดการผู้ใช้, รอบ, หัวข้อ, ตัวชี้วัด, มอบหมายบุคลากร/กรรมการ, รายงาน, Backup/Restore
- Employee: ข้อมูลส่วนตัว, เปลี่ยนรหัสผ่าน, รายการตัวชี้วัด, คะแนนตนเอง, รายละเอียดหลายรายการ, หลักฐาน, ความคืบหน้า, พิมพ์ PDF
- Committee: งานที่ได้รับมอบหมาย, หลักฐาน, คะแนนตนเอง, คะแนนรายตัวชี้วัด, ความคิดเห็น, บันทึกร่าง, ลายเซ็น, ยืนยันผล

ใช้ HTML form และ CSS พื้นฐานเพื่อให้โฟกัสการทำงานและการอธิบายโค้ด
